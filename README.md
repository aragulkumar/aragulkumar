## About

Second-year CS student. I write code, break things, and rebuild them better.

Currently focused on understanding how AI systems actually work — not just using them, but engineering them. My goal is to build an AI assistant (think J.A.R.V.I.S., not a chatbot) while developing strong backend and algorithmic foundations alongside it.

I believe in doing the fundamentals right. That means learning DSA seriously, understanding systems from the ground up, and shipping projects that solve real problems.
